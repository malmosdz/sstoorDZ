## تشغيل قاعدة البيانات (الآن)

1. أنشئ مشروعاً على https://supabase.com
2. افتح **SQL Editor** ونفّذ بالترتيب:
   1. `supabase/migrations/001_schema.sql`
   2. `supabase/migrations/002_security_rls.sql`
   3. `supabase/migrations/003_order_logic.sql`
   4. `supabase/seed/001_wilayas.sql`
3. أنشئ حسابك من صفحة التسجيل (أو من Authentication → Users)، ثم اجعل نفسك المالك:
   ```sql
   insert into admins (user_id, role)
   select id, 'owner' from auth.users where email = 'YOUR-EMAIL';
   ```
4. انسخ `.env.example` إلى `.env` وضع مفاتيحك (من Project Settings → API).

## قرارات الأمان المهمة

- **الأسعار لا تأتي من المتصفح أبداً**: الطلب يُنشأ فقط عبر الدالة `place_order()` التي تقرأ الأسعار والمخزون والشحن والكوبون من قاعدة البيانات وتحسب المجموع.
- لا توجد سياسة `INSERT` على جدول `orders` للعملاء؛ الدالة تعمل فقط بمفتاح `service_role` الموجود في الخادم.
- صلاحيات الإدارة تُتحقق من جدول `admins` عبر RLS (وليس بإخفاء الصفحات). الأدوار: `owner` · `manager` · `staff`.
- `SUPABASE_SERVICE_ROLE_KEY` للخادم فقط، ولا يوضع في JavaScript العام ولا في GitHub.
- مفتاح `anon` عام بطبيعته ومحمي بسياسات RLS.

## ملاحظات

- أسعار الشحن لكل ولاية تبدأ **معطّلة وبقيمة 0** حتى تحددها أنت من اللوحة، فلا تظهر أسعار وهمية.
- البلديات (communes) جدول جاهز، وسيُملأ في مرحلة لاحقة.
- GitHub Pages لا يشغّل Backend؛ سيُنشر الخادم على Render (المرحلة 10).
